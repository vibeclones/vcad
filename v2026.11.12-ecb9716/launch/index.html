Free, open CAD for Mac.
You can take the derivative of it.

A parametric modeler on a boundary-representation kernel we wrote from scratch in Rust. Change a dimension and the kernel rebuilds the exact solid. Ask it how the mass changes with that dimension and it returns the derivative. PCB layout, DFM and FEA run in the same app, and Claude can drive the viewport over MCP on your Mac. It needs no account, and your files stay on your disk.

How the kernel works

Four ideas, in about 285,000 lines of Rust. One part runs through all of them: the 60 × 40 × 6 mm plate from the first sample, with one hole of radius r.

1A solid is its boundary

vcad stores a part as the faces that enclose it. Each face points to an exact surface and is bounded by loops of edges, and each edge joins two vertices. The topology is a half-edge structure: every edge is two half-edges, one per adjacent face, so walking around a face or fanning around a vertex is a pointer chase.

A closed, valid boundary has to satisfy the Euler–Poincaré formula, where g counts the through-holes:

V − E + F = 2 (1 − g)(1)

Drilling the plate takes g from 0 to 1, so the right side drops from 2 to 0. A boolean that leaves a gap or a dangling face breaks the count, which makes the formula a cheap test that a result is a real solid and not just a convincing picture.

2Booleans in four stages

The hole is a difference, the plate minus a cylinder. Every union, difference and intersection runs the same pipeline.

3Exact answers to yes-or-no questions

Classification comes down to questions like "is this point above or below that plane?" In floating point, a point very close to the plane can get the wrong sign, and one wrong sign flips which side of the solid a face lands on. vcad answers these with Shewchuk's adaptive-precision predicates. The core one is the sign of a determinant:

orient3d(a, b, c, d) = sign det [ a − d,  b − d,  c − d ](2)

The predicate first evaluates the determinant in ordinary doubles with an error bound. It only switches to exact arithmetic when the result falls inside that bound, so almost every call costs about the same as the naive version. The coplanar case, where the bore's end circle sits exactly on the plate's face, is where this matters.

4Derivatives of the part

For the plate, volume as a function of the hole radius is simple:

V(r) = t (W D − πr²),    ∂V∂r = −2πr t(3)

Real parts have no closed form, so vcad gets the derivative from the kernel itself. It freezes the tessellation, lifts every surface to dual numbers from tang, and solves for how fast each mesh node moves as the parameter changes. The derivative of mass, centroid or inertia then follows from those node velocities. Reverse mode gives every parameter's gradient in one pass, and it carries on through a phyz contact simulation.

The method has limits. Gradients come from a frozen tessellation, so a change in topology, like a hole that breaks through an edge, is an error rather than a derivative. Contact gradients use phyz's penalty model, not the production collision pipeline. The paper lists both.

Files you can diff

A .vcad file is JSON. git diff shows which dimension changed, and a merge conflict is a line of text.

Board and enclosure together

The board and its housing are parts of one document, so a fit check measures the gap from every component to the case wall.

Checks before you cut

DFM marks walls thinner than the process allows and proposes the edit that fixes them. FEA colors the part by stress under the loads you pick.

Bring your agent

Claude edits the model you have open.

The app runs an MCP server on 127.0.0.1. Help ▸ Connect Claude writes the client config. From then on Claude can add features, set parameters, run DFM and FEA, and move the camera in your window. Each change lands as one named step in Edit ▸ Undo.

Without the app, npx -y @vcad/mcp starts the same kernel as a standalone MCP server.
